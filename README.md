# 灯塔服务器体系官网

「凝沙化塔」Three.js 海岸版，更新于 2026-10-17。直接双击 `index.html` 即可浏览，无需安装依赖、构建或连接字体服务。Three.js 已随项目保存在本地。人文首页的进度见 [HOMEPAGE_HANDOVER.md](HOMEPAGE_HANDOVER.md)，三维改造记录见 [THREEJS_HANDOVER.md](THREEJS_HANDOVER.md)，站点整体交接见 [HANDOVER.md](HANDOVER.md)。本轮「同心守望」与四服资料的分步进度见 [CONTENT_PHASE2_PLAN.md](CONTENT_PHASE2_PLAN.md)，用户原稿与确认修订见 [CONTENT_PHASE2_COPY.md](CONTENT_PHASE2_COPY.md)。

## 当前体验

- **海岸首页**：右侧灯塔、实体分层岩岸、守塔小屋、栏杆与礁石，以及左下的动态网格海面，由本地 Three.js 渲染，配有黄昏光照、阴影和轻微视差。天空也由着色器绘制。导航双环、大雁与文字继续使用 SVG / DOM，保留原有交互。
- **轻缓镜头**：透视相机自动横移、轻缓环绕并推拉，几秒内就能看到灯塔与岸线移动，鼠标左右移动会进一步改变视角。两道海浪及所有节点按海面上的空间位置投影，大雁按不同距离投影，天空随视角移动；节点位置、大小及追光保持一致。竖屏幅度更小，矮宽窗口限制转角以保护文字间距，触摸不会拖动镜头。进入详情或播放碎片转场时镜头停住，返回海岸后平滑继续；「减少动态效果」下停止镜头运动。标题区随海平线布局，保持文字与海上节点之间的间距。
- **两道海浪**：内环依次为灯塔镇、灯筑城、灯浮市、灯火乡；外环为种子计划的合作服务器。海浪有浪脊、波动和细碎泡沫。每环包含主线和伴随细线，进入详情后会一起变成导航弧线，因此每环看到两条细线属于现有设计。
- **追光**：屏幕光束与三维灯光共用一个平滑目标，鼠标落到石岸或小屋时照向实际表面，落到海面时照向水面；悬停任一服务器节点或靠近节点的感应范围，光束会平滑吸附并渐变为该服务器的主题色，主题光池略带柔和扩散。悬停不跳页，点击才进入。
- **种子计划**：首页第三部分保留原有星图，点击「走进种子计划」后，深色区域连同星图和文字从原位置碎裂，直接汇入总介绍的透明标识，中途不再闪回海岸，左侧底栏、双环与节点同步从屏幕左侧缓入。总介绍采用与标识呼应的浅鼠尾草绿导航、深绿文字、叶绿标题和浅暖底色，英文统一为「Seed Plan」；正文依次为计划缘起、基岩版 / Java 版适用范围，以及技术、资源资金、宣传、申请资格、审核流程五节可折叠长文（可同时展开多节，互不收起；上方有一行点按提示），文末附原提案 PDF 下载、「期待与你同行」、报名咨询人（含一键复制）与已援助 5 家服务器的说明。海面外环的四个待公布席位保留文字、编号、待公布状态与追光，但暂不允许点击跳转；配置合作服务器后恢复为独立详情入口，待公布席位页仍可通过 `#/seed/slot-N` 直接访问。总介绍与单独服务器各有入口。
- **海面互动**：移动鼠标产生细小涟漪；点击或轻触海面产生扩散波纹。
- **双环转场**：同一组海浪与节点平滑变为左侧向右凸的双弧。详情导航保留服务器名称与第二行类型，选中的名称和节点轻微放大；切服时左侧节点位置保持稳定。
- **服务器主题**：灯塔镇蓝白、灯筑城橙白、灯浮市绿白、灯火乡金白。导航背景直接使用对应主色，并柔和过渡到浅色详情页。
- **四服正式资料**：使用 Beacon Town / Beacreative / Beatorini / Bearcade 及各服服训，移除世界编号、配色注释与旗帜标签。仅保留「服务器介绍」「领导成员」两个页签，正文按段落阅读，已知群号和联系方式可复制。号码区域支持原生选择，右键与长按不会误触返回海岸。
- **回到海岸**：详情页右键、移动端长按空白处约 0.7 秒、按 Escape 或点击「返回海岸」。滑动和多点触摸会取消长按。
- **向下探索**：圆角梯形的岸线两侧保留海与岩岸，首先呈现苏轼行书题词「此心安处是吾乡」，题词位于梯形中心上沿与两侧下沿之间的中央，署名及后续所有章节同步上移，字号与字体保持原样；下方以浅色横线分隔第一部分。「四海同光」使用普通衬线字体规整纵排，与右侧五段介绍上下等高，旁边是小号竖排「灯塔服务器体系介绍」。窄屏改为正文上方的横排标题与小标题；第二部分为「同心守望」：左侧分机构展开完整介绍，默认打开布帆委，右侧使用与第一部分呼应的四色竖排大字和完整小标题；手机将标题置于正文上方。后续为种子计划与论坛入口。原第一部分的四服卡片、历史与人员调度页签已撤下，海上服务器入口仍可使用。
- **品牌与书法**：全站使用「灯塔服务器体系 / Beaconia Network」，首屏理念为「人本、人文、人情——让每一束微光，都有归处」。页眉与浏览器标签页使用青蓝六边形服务器徽记，页脚使用同尺寸的绿色版（`assets/brand-icon-blue.png` / `brand-icon-green.png` / `favicon.png`）。两环分别为「系内服务器 / Constituent Server Units」「种子计划服务器 / Seed Plan Servers」。苏轼题词以本地 WOFF2 子集嵌入 CSS，无需访客安装字体或连接外部服务；原黄庭坚子集仍保留在资源中，当前排版不再调用。
- **第一部分的视觉细节**：「四海同光」采用深青、海绿、灰绿和暖金四色，配淡潮汐轮廓、小幅灯塔章印和细线标记。五段正文统一使用宋体，第一段仅通过略大字号和较深颜色标出总起层级，重点词加浅色底纹；图形由内联 SVG 与 CSS 制作，桌面与手机均有对应排版。
- **大雁**：缓慢掠过天空，悬停或轻触时两翼同步拍动一次；可配置一句话介绍，悬停显示，点击固定，再次点击或 Escape 收起。四只大雁分别携带服庆日与档庆日、第一届布帆委常务委员、服联成立日、灯塔工业日的问答。
- **首次开场**：唯一可见文字为「凝沙化塔」。三角沙粒从地面旋转汇聚为灯塔，完成度受真实资源加载与三维首帧就绪限制；同一个完整灯塔随后携带灯光平移、缩放到主页右侧，天空、海面、岩岸和入口分层进入。结束前锁定操作，回访使用简短入场，页脚可重播。
- **碎片转场**：点击节点后灯塔拆成数百片三角形，汇成该服实际旗帜；海浪同时变成左侧双弧，天空与岩岸退场。返回时旗帜重新构成灯塔。导航与背景使用对应服务器主题色。
- **服务器之间切换**：先在旧页面拆解原旗帜，保留旧导航选中态和配色；碎片沿同一条连续轨迹运动，在途中同时切换内容、选中节点与主题，继续汇成新旗帜。交接时碎片不悬停，新文字立即开始入场；原图与碎片画布同帧交接，避免旗帜闪回。
- **适配**：竖屏有独立海岸构图；支持键盘、浏览器前进后退与「减少动态效果」。Three.js / WebGL 2 不可用时恢复原来的 SVG 岩岸和 Canvas 灯塔；海面使用原生 WebGL 或 Canvas。三维上下文丢失时自动回到 Canvas 海面，导航继续可用。阅读服务器详情时停止绘制隐藏的三维场景。

四个机构介绍、四服介绍、已确认的领导成员和联系方式已录入。灯塔镇由一组三会直属领导；灯火乡的服主与书记暂未选举、群号待定。成员图片后续再补，目前只展示文字资料。种子计划合作服务器的具体名单与论坛地址尚未提供：海面外环保留四个待公布席位（保留文字但暂不可点击跳转，席位页仍可直链访问），总介绍改为已援助 5 家服务器的说明；页脚论坛文字保留但不可点击。没有接入实时在线人数、账号或论坛后端。

## 填写资料

集中编辑 `data.js`，保留未填写的数组为 `[]`。正文按纯文本显示。`overview` 已填入用户提供的五段正式介绍，段落以空行分隔；`history` / `personnel` 数据保留，但本轮首页不再展示其页签。

| 字段 | 内容 |
| --- | --- |
| `overview` / `history` / `personnel` | 体系介绍、历史事件、人员调度 |
| `worlds` | 四个子服的介绍、旗帜、主题、服训、领导成员及群号；历史数据保留但四服页面不再展示历史页签 |
| `organizations` | 一组三会完整介绍；支持继续追加并列的职责条目 |
| `seedPlan` | 种子计划详情：两段引言、BE / JE 适用范围、`sections` 五节正文与结尾；段落以空行分隔，各节按顺序折叠、可同时展开 |
| `seedDescription` | 旧版单段种子计划说明；仅在未配置 `seedPlan` 时作为回退 |
| `partners` | 合作服务器资料；自动进入外环，每组显示最多四个 |
| `skyNotes` | 大雁携带的一句话介绍，按顺序对应四只大雁 |
| `forumUrl` | 完整 HTTP / HTTPS 论坛地址；留空时页脚「社区论坛」保留文字显示但不可点击，填写后恢复入口 |

合作服务器示例（请填写真实内容）：

```js
{
  id: 'stable-server-id',
  name: '真实服务器名称',
  type: '玩法类别',
  description: '服务器介绍',
  url: 'https://真实官网地址',
  color: '#a8c7b4',  // 海上追光与导航背景
  ink: '#35624e',    // 深色文字
  tint: '#eef5ef',   // 详情浅底
  flag: '',         // 可选，本地旗帜路径
  history: [],
  leaders: []
}
```

旧格式 `{ name, description, url }` 也支持，会使用种子计划的默认绿色主题。建议提供稳定 `id`，避免调整名单顺序后改变详情链接。颜色使用六位十六进制格式。

大雁的一句话介绍：

```js
skyNotes: [
  { title: '真实奖项或标题', text: '一句话介绍。' }
]
```

不填时，大雁只响应振翅，不出现空白说明框。历史与人员条目仍为 `{ date, title, description }`；四服成员格式为 `{ role, name, handle, contact }`，未选举可使用 `{ role, name: "", status: "暂未选举" }`。`leadershipNote` 用于灯塔镇的直属领导说明，`tagline` 为服训，`group` 为群号字符串，`groupStatus` 为未确定时的状态。`summary` 与机构 `description` 用空行分段。当前成员图片形式未定，不配置头像。

## 文件与预览

- `index.html`：持久场景、双环、开场与内容容器。
- `styles.css`：基础排版、服务器主题、响应式布局与动效。
- `home.css`：品牌、长文案双环标识、题词对齐与分界线、规整标题和体系正文。
- `content.css`：第二部分左文右题、分机构展开、四服正文与领导成员、群号和联系方式、种子计划长文档案与折叠章节。
- `assets/calligraphy-fonts.css`：苏轼及黄庭坚字体的 11 字 WOFF2 子集，以数据嵌入以兼容本地文件浏览。
- `tools/prepare-inscriptions.py`：从用户的 WPS 苏轼字体和本机黄庭坚字体重建子集，需要 `fonttools`、`brotli`；访客浏览不需要此工具。
- `cinema.css`：开场编排、场景分层入场、碎片转场配合与岸线过渡。
- `coast3d.js`：Three.js 透视相机、参考视角和空间投影、灯光、实体海岸、共享灯塔、沙粒着色器、动态海面与图形降级。
- `cinema.js`：共享灯塔网格、凝沙与归位编排、旗帜碎片迁移、操作锁定及软件投影降级。
- `ocean.js`：降级时使用的原生 WebGL / Canvas 海面。
- `scene.js`：将潮线、节点和大雁投影到当前视角，编排潮线变形、追光、海面与涟漪绘制。
- `app.js`：路由、内容、页签、手势、开场、大雁与种子分页。
- `data.js`：正式资料。
- `vendor/three-r180.js`：本地 Three.js 0.180.0；附 `THREE-LICENSE.txt` 和来源说明。无需 CDN 或模块服务器。
- `assets/coast-shore.svg` / `assets/coast-mobile-shore.svg`：降级时横屏、竖屏使用的岩岸图层；原 `coast.svg` / `coast-mobile.svg` 保留作为旧版完整构图参考。
- `assets/*.webp`：实际旗帜；原旗帜 PNG 保留为备份。
- `assets/seed-plan-mark.png`：用户最终选用的圆形 Seed Plan 徽记（透明 PNG），页面与转场共用，部署时需保留；旧的 `seed-plan-logo.png` 与单株 `seed-plan-sprout.png` 只作本地对照，不进入部署包。
- `assets/seed-plan-proposal.pdf`：种子计划原提案，供总介绍底部的小字链接下载，部署时需保留。
- `assets/brand-icon-blue.png` / `assets/brand-icon-green.png` / `assets/favicon.png`：页眉与标签页使用的青蓝六边形徽记、页脚使用的同尺寸绿色版，以及标签页 PNG；`index.html` 的 icon 指向 PNG，旧 `favicon.svg` 只留本地对照，不部署。
- `tools/verify.py`、`tools/verify-cinema.py`、`tools/verify-three.py`、`tools/verify-camera.py`、`preview/`：浏览器验收工具和结果，不必部署。
- `HOMEPAGE_HANDOVER.md`：人文首页第一部分的实施记录、字体来源和接手点。
- `CONTENT_PHASE2_PLAN.md` / `CONTENT_PHASE2_COPY.md`：第二部分与四服详情的进度、确认结果及原文档案。
- `tools/verify-content.py`：本轮正式文稿、成员信息、复制、机构交互与多尺寸排版验收。
- `tools/verify-seed-light.py`：种子总介绍与独立外环入口、透明标识、区域碎裂、实体追光和本地文件收尾验收。
- `tools/vendor-three.py`：重新校验、下载并包装固定版本的 Three.js；仅此维护命令需要联网。

也可在项目目录启动本地服务：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```
